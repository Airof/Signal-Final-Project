# Signal and Systems Final Project

This repository contains the final project for the **Signal and Systems** course during my fifth term. The project is divided into three main parts:

1. **Sound Processing**
2. **Image Processing**
3. **Watermarking**

---

## 1. Sound Processing
The sound processing component involves the following steps:

1. Select a sound file.
2. Play the sound.
3. Plot the sound waveform on a time-domain diagram.
4. Perform a **Fourier Transform** and plot the frequency spectrum.

---

## 2. Image Processing
The image processing component involves the following steps:

1. Select an image file.
2. Display the image using Python.
3. Perform a **Fourier Transform** and plot the frequency spectrum.
4. Perform a **Discrete Cosine Transform (DCT)** and plot the frequency spectrum.
5. Perform a **Discrete Wavelet Transform (DWT)** and plot the frequency spectrum.

---

## 3. Watermarking
The watermarking component involves integrating sound into an image and then retrieving it. The steps are:

1. Select both an image and a sound file.
2. Apply a transformation to the sound.
3. Embed (watermark) the sound into the image.
4. Extract the embedded sound from the image and recreate the original sound.
